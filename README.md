# 💰 Simulador Inteligente de Empréstimo

Um simulador de empréstimo desenvolvido com **HTML, CSS e JavaScript puro**, que permite calcular valores de empréstimo com base em diferentes cenários financeiros.

---

## 🚀 Funcionalidades

- Simulação por valor total do empréstimo
- Simulação por valor da parcela desejada
- Cálculo automático de juros
- Definição de taxa conforme tipo de cliente
- INSS e SIAPE como perfis de cliente
- Atualização automática ao alterar os campos
- Exibição do resultado formatado em moeda brasileira (BRL)

---

## 🧠 Lógica do projeto

O sistema trabalha com dois cenários:

### 1. Valor total do empréstimo
- Usuário informa quanto deseja pegar
- Sistema calcula:
  - juros
  - valor da parcela

### 2. Valor da parcela
- Usuário informa quanto pode pagar por mês
- Sistema calcula:
  - valor aproximado liberado
